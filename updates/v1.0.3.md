# DoshyOS 1.0.3 — multi-monitor swap fix

## Updating an existing installation

Open **Settings → System updates → Check for updates**, select **Install update**,
and restart after installation.

## Display fix

Swapping monitors now recalculates the complete RandR framebuffer from the active
screen sizes and positions, then clears the old output state before applying the
new layout. This fixes incorrect mouse coordinates and distorted or clipped output
when a larger monitor changes sides.

The saved main screen and monitor layout behavior from 1.0.2 is unchanged.
